## What it replaces

LocalPDF is a free open-source alternative to:

- Smallpdf
- Adobe Acrobat online tools
- ILovePDF
- Other paid or freemium PDF websites that upload your files

All processing stays on your device.

## Features

- Merge multiple PDFs
- Split PDF into single pages
- Rotate pages
- Download results instantly
- Dark, clean interface
- Zero backend

## Use it locally

Open `index.html` in any modern browser.

No install. No build. No data leaves your computer.

## Tech

Pure frontend. Uses [pdf-lib](https://pdf-lib.js.org/) via CDN.
